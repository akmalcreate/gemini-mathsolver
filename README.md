# 🧮 Math Gemini AI

An AI-powered web application that extracts and solves math equations from uploaded images using the Gemini API. Built with a serverless architecture for high performance, accuracy, and seamless deployment.

---

## 🚀 Live Demo

Check out the deployed application here:
👉 **[gemini-mathsolver.vercel.app](https://gemini-mathsolver.vercel.app)**

---

## ✨ Features

- **Image-to-Math Processing:** Upload images containing math equations for instant extraction and step-by-step solutions.
- **Powered by Gemini API:** Leverages Google's advanced AI models for precise problem-solving.
- **Serverless Backend:** Built with custom API routing, rate-limiting, and error-handling optimized for Vercel Serverless Functions.
- **Clean UI/UX:** Fast, responsive, and intuitive interface designed for smooth user experience.
